# RattiClient

RattiClient is an independent Windows launcher for Minecraft: Java Edition.

It is intended for players who already own Minecraft: Java Edition. Players sign in through Microsoft's official device-code flow. The launcher uses Xbox Live, XSTS, and Minecraft Services to verify game ownership and retrieve the Java profile needed to launch the game.

RattiClient does not collect Microsoft passwords. It is not affiliated with or endorsed by Mojang or Microsoft.
